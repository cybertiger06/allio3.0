macOS: los paquetes no estan notarizados por Apple. Abre el DMG y arrastra Allio Client a Aplicaciones.

Linux: instala Flatpak y abre el archivo `.flatpakref`. Usa el repositorio firmado de Allio, no una ficha de Flathub. El mismo enlace selecciona la arquitectura del equipo. Las actualizaciones se reciben mediante `flatpak update`.

La compatibilidad de los mods con cada sistema y arquitectura depende de sus autores.
